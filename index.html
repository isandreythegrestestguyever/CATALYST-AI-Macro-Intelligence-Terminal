Set both the neutral band and cost allowance in the price units of your uploaded instrument. Labels use only the selected future horizon; features use data available at each forecast point. Horizon overlap is embargoed between train, calibration, and test.

MODEL AND EVALUATION

Transparent benchmark

Three-class regularized softmax regression on lagged log returns and past-only rolling volatility. Features are standardized using each fold's training history. Class probabilities are temperature-scaled using the preceding calibration slice. An expanding-window evaluation tests on later, unseen bars. No forward-filled market or macro data enters the model.

TRANSPARENCY

Data & limitations

CATALYST prefers an explicit unknown to a confident guess.

What the site fetches

On page load, the browser requests the current U.S. Treasury nominal and real daily yield curves and public GDELT news documents. You can refresh both feeds from the overview. FRED time series and release dates require a user-provided API key. The site has no streaming futures price feed, licensed consensus, or server-side point-in-time store.

Forecast scope

The price-only walk-forward baseline runs only on an imported close series. FRED and Treasury inputs are descriptive context and are not joined to the model. Any displayed probability is experimental, carries its holdout metrics, and is withheld when predefined sample/benchmark gates fail.
